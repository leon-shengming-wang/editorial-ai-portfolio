# Case 02: Context changes the verdict

An original, AI-assisted demonstration of multi-turn response evaluation. Inspired by Leon's personal observations about response scope and conversational timing. The workshop, requests, answers, and proposed rationales are synthetic. They are not confidential tasks, real model outputs, or judgments Leon has personally reviewed and approved. No live model or audio test was conducted.

## The question

When should a concise answer be preferred, and when does it leave the user without what they asked for?

The four checkpoints isolate different issues:

1. A duration-only question: a direct answer avoids unsolicited planning.
2. An explicit follow-up: the same duration-only answer now misses part of the request.
3. A scope correction: acknowledging the request is not the same as following it.
4. A wrong core duration: fluency and brevity cannot compensate for a material factual error.

## What to inspect

For each pair, identify the current request, compare against the supplied fictional facts, and describe the effect of each difference. Keep positive and negative observations separate. Preferring B does not imply that B is flawless.

The proposed preference sequence is A, B, A, B. This is a transparent proposed analysis, not a scored answer key, measured model result, or universal platform rubric. Reviewers can disagree, but should cite evidence and explain the trade-off.

## Evidence boundary

This is a text-only exercise inspired by voice-interaction review. It cannot establish response latency, interruption timing, pronunciation, audio quality, or vocal naturalness. Repeated acknowledgment words can be discussed as text redundancy; that alone does not prove unnatural speech. No private recordings, client prompts, platform rubrics, newspaper PDFs, or private conversation links are included.
